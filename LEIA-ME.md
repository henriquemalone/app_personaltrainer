# Treino – app pessoal (PWA)

## Publicar (GitHub Pages, grátis)
1. Crie um repositório no GitHub (ex.: `treino`).
2. Envie TODOS os arquivos desta pasta para a raiz do repositório.
3. Settings → Pages → Source: "Deploy from a branch" → branch `main`, pasta `/ (root)` → Save.
4. Em ~1 min o app fica em `https://SEU-USUARIO.github.io/treino/`.

## Instalar
- iPhone: abra o link no **Safari** → Compartilhar → "Adicionar à Tela de Início".
- Android: abra no **Chrome** → menu ⋮ → "Instalar app".

## Atualizar o app
Edite os arquivos, aumente `VERSAO` em `sw.js` (ex.: `treino-v2`) e faça o push. Seus dados não são afetados.

## Dados
Ficam só no aparelho (IndexedDB). Use Ajustes → Exportar backup regularmente.
